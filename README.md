# XToys scripting notes

This repository contains guides, architecture notes, example reviews, and
working instructions for XToys scripts, with a focus on Bondage Club and
Veratown integrations.

**Start at the [XToys documentation site](docs/index.md)** for the ordered
documentation index. Script exports, builders, tests, and tools remain in
their source folders in this repository.

## Contributing

Documentation lives in `docs/`, organized into:

1. **Guides** — XToys scripting and reference material.
2. **Architecture** — integration analysis and bridge proposals.
3. **Examples** — reviews and runnable example files.
4. **Working instructions** — setup and usage for maintained scripts.

The GitHub Pages workflow builds the site from `docs/`. When editing a
generated XToys export, update its builder and focused tests, then run the
commands listed on that script's working-instructions page.
