# XToys documentation

Reference material and maintained examples for writing [XToys](https://xtoys.app)
scripts, especially scripts driven by Bondage Club and Veratown events.

## Documentation

1. [Guides](guides/) — learn script concepts, JSON, JavaScript, and the Veratown
   event contract.
2. [Architecture](architecture/) — understand the BC integration and the
   Veratown bridge design.
3. [Examples](examples/) — review script designs and find importable source
   examples.
4. [Working instructions](working-instructions/) — configure, test, and use
   maintained XToys modules.

Start with the [scripting guide](guides/scripting-guide.html), then use the
[script JSON reference](guides/script-json-reference.html) and
[JavaScript cookbook](guides/javascript-cookbook.html) as references.

## Repository

The documentation site is built from `docs/`. Importable exports and source
files remain in the repository's [`scripts/`](https://github.com/Veratown/xtoys/tree/main/scripts),
[`examples/`](https://github.com/Veratown/xtoys/tree/main/examples), and
[`tools/`](https://github.com/Veratown/xtoys/tree/main/tools) directories.
