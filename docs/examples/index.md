# Examples

Reviews and source examples for XToys scripts. The JSON exports and utilities
are maintained in the repository and linked from the
[example reviews](example-reviews.html).

1. [Example script reviews](example-reviews.html) — analysis of supplied and
   public scripts, diagnostic tools, and starter exports.
2. [BC webhook starter](https://github.com/Veratown/xtoys/blob/main/examples/bc-webhook-starter.json) —
   minimal importable webhook script.
3. [Veratown bridge test](https://github.com/Veratown/xtoys/blob/main/examples/veratown-bridge-test.json) —
   diagnostic export for bridge event testing.
